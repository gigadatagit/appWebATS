# Plantillas SST heredadas

Las plantillas vigentes para documentos SST estan en el directorio raiz `templates/`.
Esta carpeta queda reservada para artefactos historicos o material de comparacion.

No agregues aqui nuevas plantillas para generacion. Registra cada formato HTML en
`ats_reflex_app/services/sst_formats.py` y crea su archivo en `templates/<formato>/template.html`.
